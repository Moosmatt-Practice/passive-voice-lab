Ready to switch the focus?

In the active voice, the object receives the action. In the passive voice, it becomes the subject.

Active: The baker bakes the pies.
Passive: The pies are baked (by the baker).

Grammar toolbox — tap to revise

Recipe: ① Find the object → ② Move it to the front → ③ Choose BE → ④ Add the past participle → ⑤ Add by + agent only when useful.

Present simple: is/are + participle
Past simple: was/were + participle
Present perfect: has/have been + participle
Present continuous: is/are being + participle
Future: will be + participle

Important: The tense stays the same when you transform a sentence.
